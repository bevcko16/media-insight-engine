# Reporting preferences: Example Client (fictional)

- Language: British English
- Default output mode: Client-Ready Insights followed by a short Recommendations table
- Number of insights: at most five
- Headlines: yes, one line, a finding not a label
- Number formatting: 1 decimal for percentages, pp for rate differences
- Avoid: "efficient", "strong", "best-performing"
- Recommendations: separate section, never inside insights
